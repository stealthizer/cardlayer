Card Auto-detection

If your image filename starts with any of these patterns, the app will automatically detect the card type and set the correct dimensions:

Filename patterns (at start):
  • pilot- → Standard card (63.5×88mm)
  • upgrade- → Standard card (88×63.5mm)
  • dial-front- → Front dial (50mm)
  • dial- → Inner dial (43mm)
  • tile base - size / base tile - size
    → Ship base (size: small/medium/large/huge)

Examples:
"pilot-luke-skywalker.png" → standard card
"tile base - small - x-wing.png" → small base
